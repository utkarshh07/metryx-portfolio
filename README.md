⚙️ Running Locally
Clone repository
git clone https://github.com/utkarshh07/metryx-portfolio.git
cd metryx-portfolio

Install dependencies
npm install

Start development server
npm run dev


Visit:

http://localhost:5173

🏗 Production Build
npm run build
npm run preview
